# 关于页说明

## 文档范围

本页定义 Mira 桌面端“关于”页面的职责和数据边界。它不是产品能力总览，也不替代版本发布说明和当前实现文档。

## 页面职责

“关于”页面当前承担两类信息展示：

1. 应用身份与版本；
2. 简短的产品定位说明。

页面不应承载完整架构、配置指南、路线图或历史施工记录。

## 版本信息

关于页可显示：

| 字段 | 说明 |
| --- | --- |
| 应用名称 | UIChat Mira |
| 当前版本 | 当前安装包或应用元数据中的版本 |
| 最新版本 | 从公开 Release / Tag 来源读取的最新稳定版本 |
| 项目仓库 | 主源码仓库 |
| 文档入口 | tomz.io 文档站 |

当前安装版本和远端最新版本必须分开显示。远端检查失败时，应保留本地版本并明确标记检查状态，不把网络失败解释为“已经是最新版”。

## 产品说明

关于页的产品说明保持简短，只表达以下稳定定位：

> UIChat Mira 是一个本地优先、桌面优先、多 Provider 的个人 AI 工作台。聊天是入口，模型、知识、角色、工具和任务在同一环境中协作。

完整定义见：[Mira 是什么](/docs/about/origin)。

## 信息来源

关于页中的信息应来自稳定数据源：

```text
Application Metadata
→ 当前应用名称与版本

GitHub Release / Tag
→ 远端最新版本

Static Product Copy
→ 产品定位与公开链接
```

不得从聊天记录、用户私人数据或未发布的施工分支生成关于页内容。

## 页面边界

关于页不负责：

- 展示所有功能是否可用；
- 判断 Provider、MCP 或 Runtime 健康状态；
- 展示完整 Changelog；
- 承载用户账号和许可证管理；
- 记录作者私人信息；
- 用愿景文字替代当前能力说明。

功能状态见：[当前实现快照](/docs/status/current)。版本变化见 GitHub Release 和对应 Changelog。

## 失败处理

当远端版本检查不可用时：

- 页面继续显示当前安装版本；
- 显示“无法检查更新”或等价状态；
- 不阻塞应用正常使用；
- 不缓存或展示未经验证的版本号。
