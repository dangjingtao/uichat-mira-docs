# Sitemap

本站按产品认知、能力、架构、工程与现状组织公共文档。首页适合建立整体印象，下面的顺序适合系统阅读。

## 认识 Mira

从品牌起源、作者与产品地图开始，理解 Mira 为什么存在以及当前覆盖哪些领域。

## 产品哲学

本地优先、可控自主、证据先于答案，是架构和交互判断共同依赖的三条原则。

## 产品能力

对话工作区、知识与评测、角色、工具、MCP 与 MicroApps Hub，描述用户真正能够进入的产品空间。

## 架构

桌面运行时、Agent、Harness、Provider、上下文与 MicroApps 独立 Runtime，解释能力如何被组织、接入和约束。

推荐顺序：

1. Agent 当前运行真相；
2. Harness 与工具边界；
3. MicroApps 与独立 Runtime；
4. Provider 与上下文相关说明。

## 工程

源码地图、文档系统、开发与验证，提供继续阅读 `dev` 分支和参与开发的入口。

工程现场文章用于解释合同如何形成，但当前事实仍以产品文档、主仓库 current truth、代码和可重复验证为准。

## 现状与方向

当前实现快照只记录可核对事实；下一段路明确标为方向，不与已交付能力混淆。

## 使用搜索

按 Ctrl + K 或 Command + K 可搜索标题、描述与 Markdown 正文；方向键选择，Enter 打开，Esc 关闭。
